# nektony-release

Automated mirror of official Nektony macOS installers → GitHub Releases.

GitHub Actions checks the official Sparkle appcasts on a schedule, downloads any new official build, records its SHA-256, and publishes it as a Release. Binaries are the unmodified official builds, kept for archival / offline use. Full list in [`MIRRORED.md`](MIRRORED.md).

Channels: App Cleaner & Uninstaller · Funter · Disk Expert.

> Unaffiliated with Nektony. All binaries are the vendor's unmodified official builds, redistributed for archival / offline use only.
